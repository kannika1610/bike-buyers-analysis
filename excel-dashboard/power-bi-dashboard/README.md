Power BI Dashboard - Bike Buyers Analysis

Overview
This dashboard is built using Power BI to create interactive visual insights from Bike Buyers dataset.

Features Used
- Power BI visuals (bar, pie, line charts)
- Filters and slicers
- Interactive dashboard design

Visuals Created
- Income vs Purchase analysis
- Age group analysis
- Gender distribution
- Commute distance impact

Key Insights
- Higher income groups show different buying behavior
- Age plays a major role in bike purchases
- Interactive filters help explore data easily
