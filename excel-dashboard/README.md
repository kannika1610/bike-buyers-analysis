Excel Dashboard - Bike Buyers Analysis

Overview
This dashboard is built using Excel to analyze Bike Buyers dataset and understand customer behavior.

Features Used
- Pivot Tables
- Pivot Charts
- Slicers for filtering
- Data cleaning in Excel

Visuals Created
- Customer Age Distribution
- Income vs Purchase analysis
- Gender-based buying pattern
- Commute distance impact

Key Insights
- Income strongly influences purchase decision
- Middle-aged customers are more likely to buy bikes
- Commute distance affects buying behavior.
